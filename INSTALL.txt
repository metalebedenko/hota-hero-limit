Hero Limit для HotA

Тестовая сборка для одиночных партий с ИИ. Установщик сверяет код HotA 1.8.1.
Номер версии HD Mod свободный. Движок и функции, которые использует DLL,
должны совпасть с одной из поддерживаемых форм. Игровой прогон прошёл с
HD Mod 5.8 R31. Для установки нужна рабочая копия HotA с HD Mod.

Windows

1. Распакуйте ZIP и откройте HeroLimitSetup.exe.
2. В появившемся окне выберите h3hota HD.exe в папке игры.
3. Откройте появившийся рядом h3hota HeroLimit.exe и начните новую одиночную партию.
4. HeroLimit.log рядом с игрой показывает, включён ли лимит. Строка
   active heroes=3 означает, что ограничение включилось при запуске.

Для обычной игры используйте h3hota HD.exe. Чтобы убрать мод, закройте его
и удалите из папки игры h3hota HeroLimit.exe, HeroLim.dll, HeroLimit.ini
и созданный модом HeroLimit.log.

macOS с CrossOver

В бутылке с HotA откройте Run Command, выберите HeroLimitSetup.exe и нажмите Run.
После установки в той же бутылке выберите h3hota HeroLimit.exe через Run Command.
Кнопка Save Command as a Launcher создаст отдельный значок.

Руководство CodeWeavers

Правила и состояние сборки

По умолчанию один стартовый герой и два обычных найма на цвет. Выкуп того же
героя после побега или капитуляции и освобождение пленника сохраняют остаток
наймов. Параметры можно изменить в HeroLimit.ini перед запуском игры.

Бюджет пока хранится в памяти. Для проверки лимита играйте одну новую партию
без перезагрузки сохранений. При загрузке сборка считает стартом текущий состав.
В игре проверены обычный найм у человека и ИИ и выкуп после побега. Капитуляция
и тюрьмы подключены, их игровые проверки ещё предстоят. Сетевая игра не проверена.

Чтобы поделиться, перешлите исходный ZIP. В нём установщик и эта инструкция.
